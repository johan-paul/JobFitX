# JobFitX

JobFitX is an AI-powered application designed to help analyze and recommend job fit based on candidate profiles, skillsets, and other behavioral or contextual data.
This project was built for the IIT Delhi Hackathon.

---

## 🚀 Features

* AI-driven analysis of candidate profiles
* Backend system for data processing
* File upload support for candidate information
* Modular design for scalability
* Easy integration with additional datasets

---

## 📂 Project Structure

```
JobFitX/
│── backend/          # Core backend logic and APIs
│── uploads/          # Folder for uploaded files (ignored in git)
│── ai_models.py      # AI model definitions
│── __pycache__/      # Auto-generated Python cache (ignored)
```

---

## 🛠️ Installation & Setup

### 1. Clone the repository

```bash
git clone https://github.com/johan-paul/JobFitX.git
cd JobFitX
```

### 2. Create a virtual environment (recommended)

```bash
python -m venv venv
source venv/bin/activate   # For Linux/Mac
venv\Scripts\activate      # For Windows
```

### 3. Install dependencies

Make sure you have Python 3.9+ installed.

```bash
pip install -r requirements.txt
```

---

## ▶️ Running the Project

```bash
python ai_models.py
```

If you have a backend server inside `backend/`, you can start it with:

```bash
cd backend
python main.py
```

---

## 📌 Requirements

* Python 3.9+
* Libraries listed in `requirements.txt`

To generate `requirements.txt` from your environment:

```bash
pip freeze > requirements.txt
```
